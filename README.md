## 1. Công nghệ sử dụng
- **Frontend:** ReactJS (Vite), React Router DOM
- **Backend:** Node.js, Express.js
- **Cơ sở dữ liệu:** File System (lưu trữ bằng file `.json`)

## 2. Yêu cầu môi trường
- Máy tính cần cài sẵn **Node.js** (phiên bản v16 trở lên)

## 3. Hướng dẫn Cài đặt & Chạy dự án

Dự án chia 2 phần chạy độc lập. Mở **2 cửa sổ Terminal** để chạy song song.

### Bước 1: Khởi động Backend (Máy chủ API)


cd backend 
npm install express
node server.js
Lưu ý: Backend sẽ chạy tại http://localhost:3001. Hệ thống sẽ tự động sinh thư mục data/ chứa các file JSON. Vui lòng không xóa thư mục này khi đang chạy ứng dụng.
Bước 2: Khởi động Frontend (Giao diện)
Mở Terminal 2, di chuyển vào thư mục frontend và chạy lệnh:
cd frontend
G
npm install
npm run dev
Lưu ý: Frontend sẽ chạy tại http://localhost: 5173 (hoặc cống khác hiển thị trên terminal). Mở đường dẫn này trên trình duyệt (Khuyến nghị Google Chrome) để sử dụng hệ thống.
